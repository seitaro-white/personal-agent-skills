Draft a plan for the work discussed in the conversation. Inspect the relevant project context as needed and use your normal planning approach.

Include the user goal and agreed constraints near the top so the plan can be passed to a reviewer with that context intact. Keep assumptions or unresolved questions distinct from agreed requirements.

Return the draft plan without implementing it.
